# Sumiran — Local + Android APK Setup

A calm, offline-first mantra counter built with **React 19 + TanStack Start + Vite + Tailwind v4**, backed by **Supabase** (your own self-hosted or cloud project).

This repo has **no Lovable runtime dependency** — pure open-source stack.

---

## 1. Prerequisites

| Tool        | Min Version | Notes                                  |
| ----------- | ----------- | -------------------------------------- |
| Node.js     | 18+         | LTS                                    |
| Bun         | 1.0+        | Recommended (`curl -fsSL https://bun.sh/install \| bash`) |
| JDK         | 17          | Required by Android Gradle Plugin      |
| Android Studio | latest   | For SDK + emulator + APK signing       |

---

## 2. Configure Supabase

Edit `.env` at repo root:

```
VITE_SUPABASE_URL="https://YOUR-PROJECT.supabase.co"
VITE_SUPABASE_PUBLISHABLE_KEY="YOUR-ANON-KEY"
VITE_SUPABASE_PROJECT_ID="YOUR-PROJECT-ID"

# Server-only (needed only if you run server functions like OTP throttle)
SUPABASE_URL="https://YOUR-PROJECT.supabase.co"
SUPABASE_PUBLISHABLE_KEY="YOUR-ANON-KEY"
SUPABASE_SERVICE_ROLE_KEY="YOUR-SERVICE-ROLE-KEY"
```

Run all SQL migrations from `supabase/migrations/` in your Supabase SQL editor (in chronological order). Tables required: `profiles`, `groups`, `group_members`, `chants`, `user_chants`, `user_settings`, `user_roles`, `content_items`, `otp_requests`.

## 4. Build Android APK with Capacitor

Capacitor wraps the web build into a native Android shell.

### a) One-time setup

```bash
bun install                      # installs @capacitor/core, /android, /cli
bun run build                    # produces dist/client (SPA bundle)
bunx cap add android             # creates ./android (Gradle project)
bunx cap sync android            # copies web assets + native plugins
```

### b) Open in Android Studio

```bash
bunx cap open android
```

In Android Studio:
- Wait for Gradle sync to finish
- **Build → Build Bundle(s) / APK(s) → Build APK(s)**
- Output: `android/app/build/outputs/apk/debug/app-debug.apk`

### c) Or build APK from command line

```bash
bun run android:build
# APK at: android/app/build/outputs/apk/debug/app-debug.apk
```

### d) Iterate

After ANY web change:
```bash
bun run cap:sync                 # rebuilds web + syncs native
```

### Signed release APK

```bash
cd android
./gradlew assembleRelease
# Sign using your keystore (Android Studio → Build → Generate Signed Bundle/APK)
```

## 5. App identifiers

Edit `capacitor.config.ts` to change:
- `appId` (e.g. `app.sumiran.android`)
- `appName`
- splash colors

Then re-run `bunx cap sync android`.

## 6. Common issues

**`cap` not found** → `bunx cap ...` or `npx cap ...`

**Gradle JDK error** → Android Studio → Settings → Build Tools → Gradle → set Gradle JDK to 17

**Network calls fail in APK** → Supabase URL must be HTTPS. `allowMixedContent` is intentionally disabled.

**Auth OTP doesn't work in APK** → SMS/Email OTP requires Supabase Auth providers configured (Twilio for SMS, SMTP for email).

## 7. Project structure

```
src/
  routes/                  TanStack file-based routes
  components/sumiran/      App-specific UI
  components/ui/           shadcn/ui primitives
  services/                Business logic + Supabase wrappers
  store/                   Zustand-like local stores
  storage/db.ts            Dexie (IndexedDB) for offline cache
  integrations/supabase/   Auto-generated client + types
supabase/migrations/       SQL schema + seeds
android/                   Generated by `cap add android`
```
